What is JavaScript?

Role in Web Development
High-level, dynamic programming language that runs in the browser.

  • Runs directly in browser - no compilation needed
  • Makes websites interactive
  • One of three core web technologies

🌐 The Web Trio

HTML → Structure (nouns)

CSS → Presentation (adjectives)

JavaScript → Behavior (verbs)

What can JavaScript do?

✅ Respondto clicks & inputs
🎨 ModifyHTML/CSS dynamically
📡 Fetchdata from servers
🎮 Createanimations & games
📱 Buildmobile/web apps
🔌 Controlbrowser features

Control Structures: Conditionals

if / else if / else

Switch Statement

default:

Loops in JavaScript

🔁 for loop
for (let i = 0; i < 5; i++) {
  console.log(i);
}
⏳ while loop
let i = 0;
while (i < 5) {

  i++;
}
⚡ do...while

do {
  console.log(i);
  i++;
} while (i < 5);
💡 Loop Control: break exits the loop, continue skips to next iteration

Inside {} with let/const

Putting It All Together

HTML

<p id="counter">0</p>
<button id="incrementBtn">
  Click me!
</button>

JavaScript

let count = 0;
const display = document.getElementById("counter");
const btn = document.getElementById("incrementBtn");

btn.addEventListener("click", () => {
  count++;
  display.textContent = count;
  if (count > 5) {
    display.style.color = "red";
  }
});
✅ Each click increases the counter → Turns red after 5 clicks → Shows dynamic interaction!
