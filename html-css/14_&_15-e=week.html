🌿 Document Object Model (DOM)

DOM represents HTML as a tree structure. JavaScript uses DOM to access & modify webpage elements dynamically.

<body>
    <h1 id="title">Welcome</h1>
    <p class="text">Hello Students</p>
</body>

👉 Every element becomes a node – JS can change content, styles, attributes.

✨ JavaScript DOM Capabilities

  • ✏️ Change text / HTML content
  • 🎨 Modify CSS styles dynamically
  • ➕ Add new elements
  • ❌ Remove existing elements
  • 🖱️ Handle user actions (clicks, inputs)

⚖️ CSS Specificity

Order of priority: Inline > ID > Class > Element.

This text shows specificity: ID overrides class/element.

p { color: blue; }      /* element */
.text-spec { color: green; } /* class */
#title-spec { color: red; }  /* ID wins → red */
